# Expanded simulator client portraits

Production files: `public/simulator/harper.png`, `quinn.png`, `riley.png`, and `jamie.png`. Generated through the built-in image generation tool, using Morgan and Avery as style and composition references. The original portraits remain unchanged. Each new portrait is a 1254 × 1254 PNG with an alpha channel and was visually inspected before use.

## Prompt set

## Harper

Use case: stylized-concept. Create ONE production transparent PNG business-client sprite for a consultancy roleplay game. Input reference images are STYLE AND PROPORTION REFERENCES ONLY; create the new person described here, not either existing person. Subject: HARPER, a busy decisive business client: woman in her early 40s, warm light skin, short swept-back charcoal hair, teal tailored blazer over cream blouse. One hand holds a phone low at waist, the other hand raised slightly as if interrupting with a confident assumption. Looking directly at viewer with an alert knowing raised eyebrow and slightly impatient half-smile. Match the references' crisp chunky square-pixel art, detailed pixel shading, expressive oversized head, and waist-up composition cut at belt. Center on square canvas, same scale as references, filling about 85% of height, fully contain head, arms, hands and waist with generous transparent margin. Genuine transparent alpha background. No UI, words, labels, frames, circles, glow, scenery, checkerboard pattern, ground shadow or other people. Must read clearly at 150–300 pixels tall.
