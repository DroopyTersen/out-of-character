## Independent review and corrections

The independent Astra session and Opus implementation review both identified a connecting-session cleanup regression. A paid connection that never reached ready could bypass lifetime enforcement. Connecting attempts now retain abandonment cleanup and a sixty-second startup deadline, including late ready requests and continued polling. Slow successful setup refreshes browser contact without extending that deadline. Automatic server endings also mute the browser microphone before final grading. Added capacity tests prove the short quiet drain and the twenty-second maximum drain separately.

Astra also reproduced a historical evidence omission: retaining an earlier false-positive citation could exclude a later valid middle passage. Evidence questions now cover every eligible passage in batches of at most 254 IDs plus none. Each question sees the full dialogue. This removes deterministic omission; probabilistic judgment and citation mistakes remain possible. Short nonempty skill evidence retains its existing required-quote behavior. A final assessment may correct earlier confirmations; adding hysteresis solely to preserve an unsupported citation was declined.

Real provider probes exposed a second limit: packing all evidence questions into one request exceeded Jev context limits at 500 trainee passages / 60,000 spoken characters. Long assessments now partition questions into fixed groups of twelve, each with the same complete dialogue. Answers and usage are combined only when every group succeeds. Inputs at or below both 128 passages and 20,000 spoken characters retain one request. The largest single-call probe completed in 425 ms; 250 long turns / 80,000 characters used partitioning and completed in 454 ms. A failed group aborts its siblings through a shared child cancellation signal. There is no retry queue, summary generator, or omitted-history fallback. The model's documented budgets are 64k tokens for state plus all questions, and 32k for state plus its longest question ([TypeSafe models](https://docs.typesafe.ai/models)). Boundary checks therefore cover speaker distribution as well as transcript size.

At the 800-passage / 80,000-character cap, all-trainee and mixed synthetic probes completed in 784 ms and 634 ms. The all-trainee grade used 216,248 input tokens across its five requests. The cap is a practical bound for tested natural-English dialogue, not a tokenizer guarantee for arbitrary text. Assessment cadence allows at most 719 live rounds plus the final round; the current scenario catalog needs up to six provider requests per long round (at most 4,320 trainee requests per attempt). Optional director calls remain separately rate-limited by their cadence. Normal dialogue is much smaller; these upper bounds are not a typical cost forecast.

The acceptance harness now checks actual production cue eligibility, not merely the winning option. The measured catalog run passes 144/147 checks: all trainee skill/objective expectations pass; one recovered-client fixture still selects ownership at 0.53, and two actual takeover cases select it at 0.56/0.53 without crossing the 0.90 send threshold. No cue is delivered in these three cases. Both reviewers advised keeping the global threshold and documenting the weak backup sensitivity. Actor instructions are the primary prevention; this release does not claim reliable automatic takeover correction.
